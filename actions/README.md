# Actions Folder

The `actions` folder contains utility functions designed to retrieve and process data from the database. These functions facilitate reporting, analytics, and data aggregation for the application. Each file focuses on a specific metric or data visualization.

## Files in This Folder

### 1. **get-customers-count.ts**
- **Purpose**: Fetches the total number of customers associated with a specific store.
- **How It Works**:
  - Connects to the database using `prismadb`.
  - Counts the number of customer entries for a given `storeId`.
- **Output**: Returns the total customer count as a number.

---

### 2. **get-graph-customers.ts**
- **Purpose**: Retrieves customer growth data for the past 12 months.
- **How It Works**:
  - Generates a range of months for the last 12 months.
  - Counts the number of customers created in each month.
  - Produces a cumulative total for each month to show growth trends.
- **Output**: Returns an array of objects with:
  - `name`: The short name of the month (e.g., "Jan", "Feb").
  - `total`: The cumulative number of customers up to that month.

---

### 3. **get-graph-revenue.ts**
- **Purpose**: Retrieves revenue data grouped by month for a specific store.
- **How It Works**:
  - Fetches all paid orders for the given `storeId`.
  - Calculates monthly revenue by summing up the prices of products in paid orders.
  - Organizes revenue data into a graph-friendly format.
- **Output**: Returns an array of objects with:
  - `name`: The name of the month (e.g., "Jan", "Feb").
  - `total`: The total revenue for that month.

---

### 4. **get-sales-count.ts**
- **Purpose**: Calculates the total number of sales for a specific store.
- **How It Works**:
  - Counts all paid orders for the given `storeId`.
- **Output**: Returns the total number of paid sales as a number.

---

### 5. **get-stock-count.ts**
- **Purpose**: Fetches the total number of active (non-archived) products for a store.
- **How It Works**:
  - Counts all products associated with the given `storeId` that are not archived.
- **Output**: Returns the total number of active products as a number.

---

### 6. **get-total-revenue.ts**
- **Purpose**: Calculates the total revenue generated by a store.
- **How It Works**:
  - Fetches all paid orders for the given `storeId`.
  - Calculates the revenue by summing the prices of all products in the paid orders.
- **Output**: Returns the total revenue as a number.

---

## Key Points

- **Database Connection**: All functions rely on `prismadb` to interact with the database.
- **Input Parameter**: Each function accepts a `storeId` to ensure data is scoped to a specific store.
- **Output**: The outputs vary depending on the function, including counts, revenue totals, and graph-friendly data.

## Usage Example

Here’s how you might use these functions in your code:

```typescript
import { getCustomersCount, getTotalRevenue } from "@/actions";

const storeId = "exampleStore123";

const customersCount = await getCustomersCount(storeId);
const totalRevenue = await getTotalRevenue(storeId);

console.log(`Store ${storeId} has ${customersCount} customers and total revenue of $${totalRevenue}.`);
